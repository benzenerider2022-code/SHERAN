# Sheran Super & Bakers 🛒

A modern, fully responsive static website designed for a grocery and bakery business to showcase their products and services.

## 🚀 Key Features
- **Responsive Layout:** Optimized for mobile, tablet, and desktop screens.
- **Theme Toggling:** Supports both Dark and Light modes for better user experience.
- **Quick Contact:** Floating WhatsApp and Call buttons for immediate customer interaction.
- **Product Categorization:** Organized sections for Bakery items, Hot Foods, Grocery, and Ice Cream.
- **Interactive Elements:** Dynamic price updates for different product sizes and varieties.

## 🛠 Technologies Used
- **HTML5:** Semantic structure.
- **CSS3:** Custom styling, Flexbox, and Grid layouts.
- **JavaScript:** Interactive functionality, theme switching, and dynamic price calculations.

## 📦 How to Run the Project
1. Clone this repository to your local machine:
   `git clone https://github.com/BENZENERIDER2022/SHERAN.git`
